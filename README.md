# Z-API — WhatsApp Audio Demo with React

Learn how to send audio messages through Z-API from a React application. Explore this demo and use it as a starting point for adding WhatsApp audio messaging to your own projects.

**[View the Demo](https://z-api-send-audio-demo.vercel.app)** · **[Read the Documentation](https://developer.z-api.io)**

## Prerequisites

- Node.js and npm installed.
- A Z-API account with an instance connected to WhatsApp to test audio delivery.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Z-API/z-api-send-audio-demo.git
cd z-api-send-audio-demo
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm start` | Starts the local development server. |
